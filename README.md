# Terraform plans for my podman containers
---

As the title says, these are my plans for my podman containers. Based on the [decafcode](https://github.com/decafcode/terraform-provider-podman) provider.
Not all containers I use are migrated from simple `podman` commands, but these I found easier to use and declare using terraform.

These depend on the volumes to exist. I am not creating them through this repository.
